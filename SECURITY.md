# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue: use **Report a vulnerability** on the
repository's [Security tab](https://github.com/halid-ali/coin-portal/security). It opens a private
advisory that only the maintainer can see.

Include what you found, how to reproduce it and what an attacker could do with it. You will get an
answer within a week. Coin Portal is a hobby project run by one person, so there is no bug bounty.

## Supported versions

Fixes go into `main` and the next release. Older releases are not patched.
